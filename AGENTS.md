# AGENTS.md

## What this repo is

This is a GitHub **profile README** for `hanserlodev` (the repo is named after the owner), not an application. `README.md` is the deliverable: badges and SVG embeds generated by third-party services (shields.io, readme-typing-svg, github-readme-stats, github-readme-streak-stats, github-readme-activity-graph, capsule-render). A broken image is usually an upstream service failure, not a local bug — check the URL with `curl -o /dev/null -w '%{http_code}'` before swapping one in (`github-profile-trophy.vercel.app` returned 402 as of 2026-11-21 and was removed for that reason).

There is no build, test, lint, typecheck, codegen, package manifest, or lockfile. Don't spend time looking for them.

## Automation (the only executable code)

Two workflows in `.github/workflows/`, both triggered by `schedule` (`0 */12 * * *` — every 12 hours), `workflow_dispatch`, and pushes to `main`:

- `snake.yml` — generates contribution-grid SVGs via `Platane/snk/svg-only@v3` and pushes them to the **`output` branch** using `crazy-max/ghaction-github-pages@v3.1.0`, not to `main`. Username comes from `github.repository_owner`.
- `update-activity.yml` — two independent jobs:
  - `update-readme`: `jamesgeorge007/github-activity-readme@master` injects recent activity; commit message `⚡ Update recent activity`.
  - `update-repos`: `gautamkrishnar/blog-post-workflow@master` lists repos from `https://api.github.com/users/hanserlodev/repos?sort=created&per_page=5`, with `comment_tag_name: RECENT_ACTIVITY`.

Gotcha: both content-injection jobs write into marker comments located in the collapsed "Actividad y repositorios recientes" `<details>` block of `README.md`: `<!--START_SECTION:activity-->` / `<!--END_SECTION:activity-->` for activity and `<!-- RECENT_ACTIVITY_START -->` / `<!-- RECENT_ACTIVITY_END -->` for repos. Keep those markers intact when editing the README — removing them silently breaks the automation.
